# 🛠️ My Web Dev Setup Guide

A responsive technical documentation page that walks through the exact tools and steps I use to code and ship projects: VS Code, the Live Server extension, Git, GitHub, and GitHub Pages. Built with semantic HTML and CSS only — no JavaScript, no frameworks.

🔗 **Live Demo:** [https://peter-techie.github.io/naija-dev-setup-guide/](https://peter-techie.github.io/naija-dev-setup-guide/)

## 💡 Why I Built This

This is my capstone project after completing freeCodeCamp's **Responsive Design** section (media queries, mobile-first design, the Design a Piano workshop) and the **Build a Technical Documentation Page** certification project. Instead of leaving them as two separate exercises, I combined them into one real documentation page — written for a beginner developer in Nigeria, using the same tools I use every day.

## 🛠️ Skills Practiced

- Semantic documentation structure (`<nav>`, `<main>`, `<section>`, `<header>`, `<code>`, `<ol>`)
- A fixed sidebar navigation (`position: fixed`) that stays in view while the content scrolls
- **Mobile-first responsive design** with a media query that stacks the sidebar above the content on small screens, the same technique from the Design a Piano workshop
- The CSS box model and `box-sizing: border-box` for predictable sizing
- Styling `<code>` blocks to look like a real terminal
- Clean, readable typography and spacing for long-form content

## 🚀 How to Run It Yourself

1. Download or clone this repository
2. Open `index.html` in any web browser — no build tools needed
3. To edit the content, open the folder in VS Code and use the Live Server extension to see changes instantly

Introduction

This is the exact setup I use on my Dell laptop running Windows 11 to learn and build web projects. If you're starting out in Nigeria with a regular laptop and home or mobile data, this guide gets you from zero to your first live website.

Tools covered: VS Code, the Live Server extension, Git, GitHub, and GitHub Pages.

Installing VS Code

VS Code is the free code editor most developers use. Download it from the official site and install it like any other Windows program.

  1. Go to code.visualstudio.com
  2. Download the Windows version
  3. Run the installer and keep clicking "Next"
  4. Open VS Code when installation finishes
Live Server Extension

Live Server lets you see changes to your HTML and CSS instantly in the browser, without manually refreshing.

  1. Open VS Code
  2. Click the Extensions icon on the left sidebar
  3. Search for "Live Server"
  4. Click Install
  5. Right-click your index.html file and choose "Open with Live Server"
Git and GitHub

Git tracks changes in your code. GitHub stores your projects online so you can share them with the world.

git init

starts tracking a folder as a Git project.

Basic Terminal Commands

These are the commands I use every time I push a project to GitHub, one at a time, in this order:

git add . git commit -m "first commit" git branch -M main git remote add origin https://github.com/your-username/your-repo.git git push -u origin main
Deploying with GitHub Pages

GitHub Pages turns your repository into a free, live website.

  1. Open your repository on GitHub
  2. Go to Settings, then Pages
  3. Under Source, choose the main branch and / (root) folder
  4. Save, and wait one to two minutes
  5. Your site goes live at username.github.io/repo-name
